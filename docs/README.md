# docs/

Project-level documentation that doesn't belong inside a single code folder. Tracks cross-cutting deferred work and the completed-change history.

## Files

| File | Purpose |
|------|---------|
| `changelog.md` | Curated, human-readable record of completed changes ([Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format, newest first). |
| `future-todos.md` | Deferred work items discovered during plans and reviews, with context on why each was deferred. |
